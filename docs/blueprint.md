# **App Name**: MediTrack Lite

## Core Features:

- Patient Profile: Record and store patient's basic personal details.
- Treatment Logging: Log treatment details, including date, time, and observations, for each patient.
- AI-Powered Assistance: Use AI tool to provide auto-completion and suggestions for common treatments and observations.
- Patient Search: Search and filter patients based on name, date of birth, or treatment details.

## Style Guidelines:

- Primary color: Light blue (#72BCD4) for a calm and professional feel.
- Background color: Very light blue (#E0F7FA) for a clean and unobtrusive backdrop.
- Accent color: Teal (#26A69A) for key actions and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif with a modern look and a little warmth or personality.
- Use simple, clear, and recognizable icons for navigation and actions.
- Clean and intuitive layout for easy navigation and data entry.
- Subtle transitions and animations to provide feedback on user interactions.
